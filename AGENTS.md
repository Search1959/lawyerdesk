# LawyerDesk AI - Workspace & Project Rules

## Application Details
- **Official Production Domain**: `lawyerdesk.co.in`
- **Application Name**: LawyerDesk AI
- **Primary Platform**: Enterprise AI-First Legal Operating System for Indian Law Practice (High Courts, District Courts, NCLT, DRT)

## Database & Cloud Storage
- **Firestore Database**: Google Firebase Cloud Database (`hardy-diorama-njlsj`)
- **Real-Time Data Persistence**: Enabled across Matters, Legal Documents, Cause List Hearings, Clients, Invoices, Enquiries, Tasks, and Firm Management.
- **AI RAG Engine**: Grounded Gemini 3.6 Flash with PaddleOCR extracted vector search chunks.
